# Project Structure

| Directory | Description |
|------------|-------------|
| `communication` | **The bulk of the project, this is where you probably want to go.** ESP32 and ESP8266 communication examples, protocols, and networking demonstrations. |
| `documentation` | Project documentation and proposal materials. |
| `freertos` | FreeRTOS tasking examples for the ESP32. |
| `logs` | Example test captures collected during development. |
| `tools` | Utility scripts and helper programs used for log processing, analysis, and project support. |
